Para usar o Google Drive, você precisa criar um Client ID no Google Cloud (gratuito, leva 5 minutos):

  1. Acesse console.cloud.google.com
  2. Crie um novo projeto
  3. Vá em APIs e Serviços → Biblioteca
  4. Busque e ative: Google Drive API e Google Picker API
  5. Clique em Credenciais → Criar novo → ID do cliente OAuth 2.0
  6. Tipo: Aplicativo da Web
  7. Em Origens JavaScript autorizadas, adicione: http://localhost:8765
  8. Copie o ID do Cliente e cole aqui:
